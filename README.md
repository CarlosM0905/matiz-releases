# Matiz — descargas

Matiz es un ecualizador de sistema para Windows 10/11, nativo y liviano, que controla [Equalizer APO](https://sourceforge.net/projects/equalizerapo/). Trae presets de música y de juegos que se activan solos, corrección por audífono o parlante, medición del cuarto con micrófono y un panel rápido en la bandeja.

## Instalar

1. Instala Equalizer APO, marca tus salidas de audio en su Configurator y reinicia.
2. Descarga `matiz.exe` del [último release](https://github.com/CarlosM0905/matiz-releases/releases/latest) y ábrelo.
3. Pulsa **Instalar**: se copia a tu usuario (sin administrador) y aparece en el menú Inicio. Las versiones nuevas se ofrecen solas desde aquí.

Se desinstala desde *Configuración → Aplicaciones*; al hacerlo se restaura la configuración original de Equalizer APO.

Este repositorio solo contiene los ejecutables publicados.
